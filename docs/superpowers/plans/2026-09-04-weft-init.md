# weft init — M4 项目模板（实施计划）

- 日期：2026-09-04
- 依据：roadmap M4"`weft init` 项目模板与文档"；v1.1 设计对复用载体 = 跨项目拷贝文件的定位（本命令不引入全局库基础设施）
- 基线：237 passed, 1 deselected（m4-init worktree 实测）

## 目标

`weft init [PROJECT_DIR]`（默认 `.`）生成最小合法项目骨架：init 后立即 `weft validate` **0 错误 0 提醒**，用户从注释模板出发填卡片与叙事。不解决跨项目复用（方法/文献库仍按 v1.1 = 拷文件）。

## 命令语义

- 目标目录不存在 → 创建（含父目录）；存在且为空 → 原地生成；存在且非空 → `E-INIT-COLLISION`（新诊断码）列出冲突条目，退出码 1，**不写入任何文件**（fail-closed，无部分写入）。
- 成功：逐个打印已创建文件（`已创建 <rel>`），退出码 0。
- 生成文件固定 LF。

## 骨架清单

```
<dir>/
├── _quarto.yml                # project default + bibliography: assets/references.bib；csl/reference-doc 注释示例
├── weft.yaml                  # 全注释默认值模板（figures_dir / assemble_mode / paper_file）
├── index.qmd                  # 标题占位
├── assets/references.bib      # @comment 空库
├── metadata/
│   ├── figures.yaml           # 全注释模板（键 = Quarto label）
│   ├── data/  facts/  notes/  methods/  params/
│   └── claims/cited/  claims/uncited/
├── narrative/01-introduction/part-01.md   # id: sec-01, nodes: [] + 注释节点示例
└── figures/                   # 默认 figures_dir
```

## 设计决策

| # | 决策 | 依据 |
|---|------|------|
| D1 | 非空目录一律拒绝且零写入；不做"补齐缺失文件"的幂等模式 | init 是唯一从零入口，宁拒不猜用户意图；与项目 fail-closed 风格一致 |
| D2 | 骨架以"init 后 validate 0 错 0 提醒"为验收线；示例内容只以注释形式给格式参考 | 可跑的完整示例已由 examples/paper-demo 承担，骨架不应携带待清理的假数据 |
| D3 | _quarto.yml 只实体化 bibliography（指向 assets/references.bib + 空 @comment 库）；csl / reference-doc 以注释给出 | loader 的 E-BIB-MISSING 与生成期 `[@key]` 硬规则依赖 bibliography 声明链；二进制/许可资产（style.csl、template.docx）不随 init 分发 |
| D4 | weft.yaml / figures.yaml 用全注释模板 | loader 对 YAML None 安全（_load_config/_load_figures 已验证），模板即文档，零解析风险 |
| D5 | 新诊断码 `E-INIT-COLLISION`（错误，阻断），经 _print_diagnostics 输出 | AGENTS.md 红线 5：新增码必须进表——登记于本文档，总表随计划文档体系 |
| D6 | 纯函数 `init_project(root) -> list[Path]`（返回创建的文件路径）放 `scaffold.py`，CLI 薄封装；不 import engine | 与 graphgen/assemble 分层一致；数据层功能不依赖 SpecModule |
| D7 | 起步 part 放 `narrative/01-introduction/part-01.md`，`nodes: []` + 注释节点示例 | loader 只要求 part 位于章节子目录（E-PART-NO-CHAPTER），chapter 排序按路径字符串；空 nodes 是合法最小态 |
